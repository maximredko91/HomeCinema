# Home Cinema

Android-приложение для просмотра фильмов, сериалов и мультфильмов с SSD,
подключённого к роутеру Keenetic Titan через общую папку (SMB).

## Возможности

- Подключение к SMB-шаре роутера (SMB2/3, гостевой доступ или логин/пароль).
- Сканирование библиотеки: рекурсивный обход папок на диске, поиск видеофайлов,
  `.nfo` (формат Kodi) и постеров (`poster.jpg/png`, `folder.jpg/png`, `cover.jpg/png`).
- Библиотека сохраняется локально (Room), поэтому список открывается мгновенно —
  сеть нужна только при сканировании и воспроизведении.
- Карточки с вертикальным постером, под ним — название, жанр и год.
- **Фильтры по категориям** на главном экране: Всё / Фильмы / Сериалы /
  Мультфильмы / Мультсериалы. Мультфильмы и мультсериалы определяются
  автоматически по жанру в `.nfo` (Animation/Anime/Мультфильм и т.п.).
- **Сериалы и мультсериалы разбиты на сезоны и серии.** Карточка сериала
  открывает список серий, сгруппированный по сезонам, с описанием и
  отдельным воспроизведением/загрузкой каждой серии.
- Просмотр прямо в приложении (Media3/ExoPlayer, стриминг по SMB без
  скачивания файла) или через внешний плеер (например, VLC).
- **Скачивание для просмотра офлайн.** Фильм, мультфильм или отдельную серию
  можно скачать на телефон (кнопка «Скачать», с индикатором прогресса).
  Скачанные вещи помечаются значком на постере, доступны без сети и видны
  в отдельном разделе «Загрузки» (значок в верхней панели), откуда их можно
  запустить или удалить, освободив место.
- При воспроизведении приложение автоматически использует локальную
  скачанную копию, если она есть, и только иначе стримит с SMB.

## Структура проекта

```
app/src/main/java/com/homecinema/library/
├── data/
│   ├── smb/        SmbManager (jcifs-ng) + SmbDataSource (кастомный источник для ExoPlayer)
│   ├── nfo/        NfoParser — парсер .nfo (movie/tvshow/episodedetails), определение анимации
│   ├── scanner/    LibraryScanner — обход диска: сериалы (сезоны/серии) + фильмы/мультфильмы отдельно
│   ├── download/   DownloadManager — копирование видео с SMB на телефон с прогрессом
│   ├── db/         Room: MediaItemEntity (фильмы/сериалы/серии в одной иерархической таблице)
│   ├── repository/ LibraryRepository — единая точка входа для UI
│   └── settings/   SettingsStore — хранение параметров подключения (DataStore)
└── ui/
    ├── screens/    LibraryScreen, DetailScreen, ShowDetailScreen, DownloadsScreen, PlayerScreen, SettingsScreen
    ├── components/ MediaPosterCard, DownloadControlRow
    ├── navigation/ AppNavHost
    └── theme/      Тёмная "кинотеатральная" тема оформления
```

## Как собрать

1. Открыть папку `HomeCinema` в Android Studio (Koala или новее).
2. Дать Gradle синхронизироваться — он скачает зависимости
   (Compose, Media3, Room, jcifs-ng, Coil, DataStore) из Maven Central/Google.
3. Запустить на устройстве/эмуляторе в той же сети, что и роутер (Run ▶).

> Обновление базы: при первом запуске после этого апдейта локальный кэш
> библиотеки пересоздаётся (изменилась схема таблицы под сезоны/серии и
> загрузки) — просто запустите сканирование заново.

## Первый запуск

1. Открыть значок шестерёнки (настройки).
2. Указать:
   - **IP роутера** — например `192.168.1.1` (адрес Keenetic Titan в локальной сети).
   - **Имя общей папки (share)** — как она называется в списке сетевых папок
     роутера (Keenetic обычно называет её по имени диска, например `disk1_ssd1`).
   - **Подпапку внутри шары** — если фильмы лежат не в корне шары, а, например,
     в `Video/Movies`.
   - Логин/пароль (если на Keenetic включена аутентификация для сетевой папки)
     либо переключатель «Гостевой доступ».
3. Нажать «Проверить подключение», затем «Сохранить».
4. На главном экране нажать значок обновления — начнётся сканирование.

## Формат .nfo и структура папок

Фильмы/мультфильмы — по одной папке на тайтл:

```
Movies/
  Интерстеллар (2014)/
    Interstellar.mkv
    movie.nfo        <movie><title>...</title><year>...</year><genre>...</genre>...
    poster.jpg
```

Сериалы/мультсериалы — папка с `tvshow.nfo` в корне и подпапками по сезонам:

```
TV/
  Улица Сезам/
    tvshow.nfo        <tvshow><title>...</title><genre>Animation</genre>...
    poster.jpg
    Season 01/
      S01E01.mkv
      S01E01.nfo      <episodedetails><title>...</title><season>1</season><episode>1</episode>...
      S01E02.mkv
      S01E02.nfo
```

Если у серии нет отдельного `.nfo` или в нём не указаны `<season>`/`<episode>`,
сканер попытается определить номер сезона/серии по имени файла (`S01E02`,
`1x02`). Если и это не получится — серии внутри сезона нумеруются по порядку
обнаружения на диске.

## Известные ограничения / что можно доработать дальше

- Загрузка идёт в фоновом coroutine-scope приложения — переживает переход
  между экранами, но не переживает полное закрытие/выгрузку процесса
  Android. Для по-настоящему надёжных фоновых загрузок (уведомление в шторке,
  докачка после перезапуска и т.п.) стоит вынести это в `WorkManager` или
  foreground `Service` — сейчас это самая очевидная точка роста.
- Список эпизодов не показывает миниатюры серий (только постер сериала) —
  Kodi-нафо иногда кладёт `*-thumb.jpg` рядом с видео, это легко добавить в
  `LibraryScanner`.
- Определение "мультфильм vs фильм" и "мультсериал vs сериал" — эвристика по
  ключевым словам в жанре (`Animation`, `Anime`, `Мультфильм`, `Cartoon`).
  Если жанр не заполнен scraper'ом, тайтл попадёт в обычную категорию
  "Фильмы"/"Сериалы".
- Для внешнего плеера используется системный `Intent.ACTION_VIEW`: если файл
  скачан — передаётся локальная ссылка через `FileProvider` (открывается
  любым плеером), если нет — `smb://` ссылка (сработает с плеерами, которые
  сами умеют читать SMB, например VLC).
