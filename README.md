# Home Cinema

Личный медиацентр для Android: смотрит фильмы, сериалы, мультфильмы и
мультсериалы прямо с сетевого диска (SMB) — без стриминговых сервисов,
подписок и загрузки чего-либо на сторонние серверы. Библиотека собирается
автосканированием `.nfo`-файлов (формат Kodi/Radarr/Sonarr), так что готовая
медиатека с NAS/роутера подключается без ручной разметки.

Лицензия: [MIT](LICENSE).

## Возможности

### Библиотека
- **Несколько источников SMB одновременно** (SMB2/3, гостевой доступ или
  логин/пароль) — например, отдельные шары для фильмов и сериалов на разных
  дисках/роутерах. Управляются в Настройках: добавить/изменить/удалить,
  у каждого своя проверка подключения. Пароли хранятся зашифрованными
  (`EncryptedSharedPreferences`, ключ — в Android Keystore устройства), а не
  в открытом виде в базе данных приложения.
- Сканирование: рекурсивный обход папок, поиск видеофайлов, `.nfo`, постеров,
  кадров (`fanart`) и сайдкар-субтитров. Библиотека кэшируется локально
  (Room) — список открывается мгновенно, сеть нужна только при сканировании
  и воспроизведении. Прогресс сканирования показывает и число найденных
  видео вживую, и разбор метаданных по каждому тайтлу.
- **Автообновление** — фоновая задача `WorkManager` раз в сутки проверяет
  источники на новые файлы, если это не отключено в настройках; работает
  по расписанию ОС, а не только при запуске приложения. Если после
  обновления самого приложения появились новые поля из `.nfo`, которые
  требуют пересканирования, — предлагается сделать это одним нажатием.
- Один недоступный источник (например, спящий NAS) не блокирует
  сканирование остальных, а ошибка показывается понятным текстом, а не
  сырым исключением.
- **Категории**: Всё / Фильмы / Сериалы / Мультфильмы / Мультсериалы.
  Мультфильмы и мультсериалы определяются автоматически по жанру в `.nfo`.
- **Поиск** — по названию, описанию, актёрам, режиссёру и тегам; история
  последних запросов с быстрым повтором. `#тег` ищет строго по `<tag>` из
  `.nfo` и понимает запрос на русском (переводится через встроенный
  офлайн-словарь на ~40 000 слов, например `#рыцарь` найдёт тег `knight`).
- **Фильтры и сортировка** — категория/жанр/год в одном выезжающем снизу
  листе, сортировка по названию/году/жанру/рейтингу, настраиваемое число
  колонок в сетке (масштабируется под альбомную ориентацию и планшеты).
- **Коллекции** — отдельная вкладка, группирует фильмы по тегу `<set>` из
  `.nfo` (например, серии фильмов вроде Бондианы).
- **Свои списки** (плейлисты) — создание, переименование, удаление,
  добавление/удаление тайтлов; отдельная вкладка «Списки». Быстрый доступ
  к «Избранному» там же.
- **История просмотров** — отдельный экран со всем, что было начато или
  досмотрено, отсортировано по давности.
- **Алфавитный указатель** — полоса с буквами сбоку от сетки для быстрой
  прокрутки, отключается в настройках; плюс кнопки быстрого перехода в
  начало/конец списка.
- **Продолжить просмотр** — ряд над сеткой с недосмотренными фильмами,
  мультфильмами и сериями; тап сразу возобновляет воспроизведение с
  прерванного места.
- Карточка тайтла показывает постер, название (плюс оригинальное, если
  указано в `.nfo`), жанр, год, прогресс просмотра (полоса снизу) или
  значок «просмотрено», значок скачанного.

### Страница тайтла
- Кадр из фильма (`fanart`) как баннер вверху экрана.
- Год, рейтинг, длительность, страна, возрастной рейтинг, качество релиза
  (например «1080p BDRip», определяется по имени файла), доступность
  субтитров — отдельными плашками с иконками.
- Слоган, студия, описание, режиссёр и актёры (парсятся из `.nfo`); имя
  режиссёра/актёра, если в библиотеке есть другие его тайтлы, кликабельно
  и открывает его фильмографию.
- Другие части той же коллекции — рядом внизу страницы.
- **Зум изображений** — тап по кадру или постеру открывает полноэкранный
  просмотр с пинч-зумом и перетаскиванием.

### Сериалы
- Разбиты на сезоны и серии. Карточка сериала открывает список серий с
  описанием, миниатюрой (`*-thumb.jpg` или картинка с тем же именем, что и
  видео — обе конвенции Kodi), прогрессом просмотра, своим воспроизведением
  и загрузкой для каждой серии.
- Шапка экрана сериала показывает кадр (fanart), постер, метаданные,
  описание, режиссёра и актёров — как у фильма.

### Воспроизведение
- Media3/ExoPlayer, стриминг по SMB без предварительного скачивания через
  локальный loopback-прокси (совместимо с любым внешним плеером, не только
  умеющими `smb://`), либо локальная скачанная копия.
- Сайдкар-субтитры (`.srt`/`.ass`/`.ssa`/`.sub`/`.vtt` рядом с видео)
  подключаются автоматически — и во внутреннем плеере, и во внешнем
  (передаются через параметры запуска, если плеер их поддерживает).
- **Режим воспроизведения** настраивается: всегда во внутреннем плеере,
  всегда во внешнем, либо спрашивать каждый раз. Для внешнего плеера можно
  закрепить конкретное установленное приложение вместо выбора каждый раз.
- Полноэкранный иммерсивный режим (системные панели скрыты), экран не
  гаснет во время просмотра.
- **Продолжение просмотра** — позиция сохраняется автоматически, при
  повторном открытии предлагается досмотреть с прерванного места (в том
  числе и во внешнем плеере, если он это поддерживает).
- Переключение субтитров и аудиодорожек — через настройки плеера (шестерёнка
  на панели управления).
- **Жесты**: свайп вверх/вниз слева — яркость, справа — громкость, с
  индикатором на экране; тап — показать/скрыть элементы управления.
- **Скачивание для просмотра офлайн.** Прогресс, значок на постере, раздел
  «Загрузки» с возможностью запустить или удалить. Идёт через `WorkManager`
  (уведомление в шторке с прогрессом) — переживает выгрузку процесса и
  докачивает файл с прерванного места, а не с нуля.

### Настройки приложения
Сгруппированы по разделам вместо одного длинного списка: Источники,
Библиотека, Воспроизведение, Внешний вид, Хранилище, История изменений,
О приложении — каждый со своей краткой подписью текущего значения.

- **Язык** — русский или английский, переключается вручную независимо от
  языка системы; весь интерфейс переведён, включая историю изменений.
- Источники SMB (см. выше).
- Режим воспроизведения и выбор внешнего плеера (см. выше).
- Тема: системная / светлая / тёмная / OLED (глубокий чёрный) / «Стекло»
  (настоящее размытие фона, Haze) — с выбором акцентного цвета и, для
  «Стекла», цвета подложки и непрозрачности блюра.
- Число колонок в сетке, алфавитный указатель — вкл/выкл.
- Автообновление библиотеки — вкл/выкл.
- Очистка локального кэша обложек.
- **История изменений** — офлайн, список версий встроен в приложение, не
  требует сети.
- «О приложении» — версия, список возможностей, использованные технологии,
  лицензии открытого кода (включая офлайн-словарь для поиска по тегам).
- Приложение само проверяет GitHub на новую версию при запуске и умеет
  скачать и установить обновление прямо из уведомления, без перехода в
  браузер.

```
│   ├── nfo/           NfoParser — парсер .nfo (movie/tvshow/episodedetails)
│   ├── scanner/       LibraryScanner — обход всех источников: сериалы (сезоны/серии) + фильмы/мультфильмы
│   ├── media/         Сайдкар-субтитры, определение качества релиза, список установленных видеоплееров
│   ├── search/        Русско-английский словарь для #тег-поиска
│   ├── download/       DownloadManager — копирование видео с SMB на телефон с прогрессом (WorkManager)
│   ├── streaming/      LocalStreamingServer — loopback HTTP-прокси для внешних плееров и субтитров
│   ├── update/         Проверка новых версий на GitHub, офлайн-список изменений, скачивание APK
│   ├── db/             Room: MediaItemEntity, SmbSourceEntity, списки + DAO
│   ├── repository/      LibraryRepository — единая точка входа для UI
│   └── settings/        SettingsStore — DataStore: тема, плеер, автосканирование и т.п.
└── ui/
    ├── screens/     LibraryScreen, DetailScreen, ShowDetailScreen, PlayerScreen, DownloadsScreen, HistoryScreen, SettingsScreen
    ├── components/  MediaPosterCard, DownloadControlRow, ZoomableImageDialog
    ├── navigation/  AppNavHost
    ├── viewmodel/   LibraryViewModel + LibraryFiltering — фильтры/поиск/сортировка (чистая функция, юнит-тестируется)
    └── theme/       Темы (в т.ч. «Стекло»/Haze-блюр), акцентные цвета

app/src/test/         Юнит-тесты (JVM, без эмулятора) — парсер .nfo, фильтрация/сортировка, тег-поиск, тема, мелкие хелперы
app/src/androidTest/  Инструментальные Compose-тесты (нужен эмулятор/устройство)
```

## Как собрать

1. Открыть папку `HomeCinema` в Android Studio (Ladybug/Meerkat или новее).
2. Дать Gradle синхронизироваться — он скачает зависимости
   (Compose, Media3, Room, jcifs-ng, Coil, DataStore) из Maven Central/Google.
   Проект собирается Gradle 9.6.1 + AGP 9.3.1 + Kotlin 2.3.10; JDK для демона
   Gradle определяется автоматически (`gradle/gradle-daemon-jvm.properties`).
3. Запустить на устройстве/эмуляторе в той же сети, что и роутер/NAS (Run ▶),
   либо собрать APK: `./gradlew assembleDebug`
   (файл — `app/build/outputs/apk/debug/app-debug.apk`).

Минимальная версия Android — 12 (API 31): настоящее размытие фона для темы
«Стекло» технически недоступно на более старых версиях.

## Релизная сборка

`assembleRelease` собирает минифицированный (R8 + `shrinkResources`) APK.
Чтобы он был подписан, создайте локальный keystore и `keystore.properties`
в корне репозитория (оба уже в `.gitignore` — никогда не коммитятся):

```bash
keytool -genkeypair -v -keystore app/release.keystore -alias homecinema \
  -keyalg RSA -keysize 2048 -validity 10000
```

```properties
# keystore.properties
storeFile=app/release.keystore
storePassword=...
keyAlias=homecinema
keyPassword=...
```

Без этих файлов `assembleRelease` всё равно соберётся, но APK останется
неподписанным. **Потеря keystore означает невозможность обновить уже
установленные у кого-либо копии приложения той же подписью** — храните
файл и пароли отдельно от репозитория (менеджер паролей/зашифрованный диск).

## Тесты

- **Юнит-тесты** (JVM, устройство не нужно): `./gradlew test`. Покрывают
  парсер `.nfo`, разбор номеров серий по имени файла, фильтрацию/сортировку/
  поиск библиотеки (включая русский `#тег`-поиск), разрешение темы и мелкие
  хелперы.
- **Инструментальные Compose-тесты** (`app/src/androidTest`) требуют
  подключённое устройство или эмулятор: `./gradlew connectedAndroidTest`.
- **CI** (`.github/workflows/ci.yml`): на каждый push/PR в `master` —
  юнит-тесты и debug-сборка на Ubuntu.

## Первый запуск

1. Открыть значок шестерёнки (настройки) → «Источники (SMB)» → «Добавить
   источник».
2. Указать:
   - **Название** — как источник будет называться в списке (например,
     «Гостиная NAS»).
   - **IP адрес** — например `192.168.1.1`.
   - **Имя общей папки (share)** — как она называется в списке сетевых папок
     роутера/NAS (Keenetic обычно называет её по имени диска, например
     `disk1_ssd1`).
   - **Подпапку внутри шары** — если фильмы лежат не в корне шары, а,
     например, в `Video/Movies`.
   - Логин/пароль (если на шаре включена аутентификация) либо переключатель
     «Гостевой доступ».
3. Нажать «Проверить подключение», затем «Сохранить». При необходимости —
   добавить ещё один источник тем же способом.
4. На главном экране нажать значок обновления — начнётся сканирование всех
   источников.

## Формат .nfo и структура папок

Фильмы/мультфильмы — по одной папке на тайтл:

```
Movies/
  Интерстеллар (2014)/
    Interstellar.mkv
    Interstellar.srt                (необязательно — сайдкар-субтитры)
    Interstellar-poster.jpg          (или poster.jpg / folder.jpg / cover.jpg)
    Interstellar-fanart.jpg          (кадр из фильма, показывается на странице описания)
    movie.nfo        <movie><title>...</title><year>...</year><genre>...</genre>
                      <runtime>...</runtime><country>...</country><mpaa>...</mpaa>
                      <director>...</director><actor><name>...</name></actor>
                      <tag>...</tag><set><name>Коллекция</name></set>...
```

Постер и кадр ищутся как по фиксированным именам (`poster.jpg`,
`fanart.jpg` и т.п.), так и по имени видеофайла с суффиксом
(`Interstellar-poster.jpg`) — так их обычно называют Kodi/Radarr.

Сериалы/мультсериалы — папка с `tvshow.nfo` в корне и подпапками по сезонам:

```
TV/
  Улица Сезам/
    tvshow.nfo        <tvshow><title>...</title><genre>Animation</genre>...
    poster.jpg
    fanart.jpg
    Season 01/
      S01E01.mkv
      S01E01.nfo      <episodedetails><title>...</title><season>1</season><episode>1</episode>...
      S01E01.jpg      (или S01E01-thumb.jpg — обе конвенции распознаются как миниатюра серии)
      S01E02.mkv
      S01E02.nfo
```

Если у серии нет отдельного `.nfo` или в нём не указаны `<season>`/`<episode>`,
сканер попытается определить номер сезона/серии по имени файла (`S01E02`,
`1x02`). Если и это не получится — серии внутри сезона нумеруются по порядку
обнаружения на диске.

## Известные ограничения / что можно доработать дальше

- Определение "мультфильм vs фильм" и "мультсериал vs сериал" по умолчанию —
  эвристика по ключевым словам в жанре (`Animation`, `Anime`, `Мультфильм`,
  `Cartoon`). Если жанр не заполнен scraper'ом, тайтл попадёт в обычную
  категорию "Фильмы"/"Сериалы" — но это теперь можно поправить вручную: чип
  с категорией на карточке фильма/сериала открывает выбор, и ручной выбор
  переживает последующие пересканирования библиотеки.
- Раскладки под Android TV / управление с пульта (D-pad) нет — интерфейс и
  жесты плеера (свайпы яркости/громкости, алфавитный указатель) рассчитаны
  на тачскрин.
- Всё хранится только локально на телефоне (Room + DataStore) — избранное,
  списки, история просмотров и настройки не синхронизируются между
  несколькими устройствами/аккаунтами. Облачная синхронизация обсуждалась,
  но осознанно отложена — нужен отдельный backend/авторизация, а реальная
  потребность (несколько устройств одного пользователя vs. что-то другое)
  пока не сформулирована.
- Инструментальные Compose-тесты (`app/src/androidTest`) не входят в CI —
  GitHub-hosted раннеры не поддерживают аппаратную виртуализацию, нужную
  для загрузки Android-эмулятора, так что их можно запускать только вручную
  на подключённом устройстве (`./gradlew connectedAndroidTest`). CI гоняет
  только юнит-тесты и debug-сборку.
